# Unify programme NIL authority

Each college programme owns one season-bound NIL ledger whose roster allocations, recruiting
reservations, and portal reservations draw from the same annual budget. Remaining money is derived,
and moving a recruit or portal promise into the roster reclassifies the same allocation instead of
creating another one. This makes every offer, refund, signing, retention attempt, transfer, and
rollover conserve an auditable resource while preventing overlapping claims for one identity.
