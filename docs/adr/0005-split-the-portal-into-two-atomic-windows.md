# Split the portal into two atomic windows

College transfers resolve through a postseason window after redshirt and eligibility decisions and
a spring window at the start of the next season before any game. Each window resolves its complete
retention, offer, matching, scholarship, roster, NIL, career, and history transaction on copies and
commits only if the final world is legal. The postseason boundary may persist a partially filled but
position-legal roster; final walk-ons wait until spring closes so they do not erase real transfer
capacity. Recruiting remains active while portal state owns its independent phase machine.
