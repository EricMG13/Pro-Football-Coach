# Phase 4C — All-22 Arcade Field Implementation Plan

> **Status:** Stages 1–3 written and committed; every box below them ticked means the code and
> its tests exist, NOT that they compiled — this session had no Swift toolchain (see
> `docs/STATUS.md`). Stage 4 is the on-device work and is genuinely outstanding.

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the abstract aim-and-throw arcade view with a live all-22 2D field per
`06-PLAYED-GAME-MODE.md` rev 2: portrait vertical field, every player moving from real ratings,
honest openness indicators, visible pocket and run lanes, full direct control on offense,
watchable defense ramping to timed defensive inputs.

**Architecture:** A pure-Swift spatial kernel (`SnapKernel`) joins `FootballSimCore` — formation
placement, routes vs coverage, line duels, carrier pursuit — stepped at a fixed 30 Hz logical
tick, deterministic given `(players, calls, seed, InputTrace)`. It grades what the user's hands
did and feeds a widened `PlayExecution`; the engine still owns every probability and every roll
(`League.rng`). The UI renders the kernel with SwiftUI `Canvas` + `TimelineView`. Opponent plays
are resolved by the engine first, then choreographed: animation generated *from* the resolved
`PlayEvent`, never able to contradict it.

**Tech Stack:** Swift 5.10, SwiftUI, iOS 17, zero dependencies, no SpriteKit, no image assets.
Tests: hand-rolled `TestKit` executable (`swift run -c release SimTests`).

## Global Constraints

- **One engine, one truth.** The kernel never invents probabilities or draws randomness outside
  the seeded stream handed to it. Every outcome is an engine resolution.
- **Honesty invariants (tested):** indicator color never contradicts kernel geometry; animation
  endpoint always equals the emitted `PlayEvent` (spot, result).
- **Execution caps (named constants, no inline magic numbers):** completion ±0.20, yards ±6.0,
  kick ±0.18, defensive inputs ±0.10 combined. All tunables live in a new `ArcadeTuning` enum in
  `FootballSimCore/Rules/` beside `LeagueRules`.
- **Determinism under trace:** same players + calls + seed + `InputTrace` ⇒ identical grades and
  identical frames. All kernel tests run headless.
- Portrait only, app-wide. Ratings 40–99 ints. Fictional identity everywhere.
- Accessibility: indicator shape-coding, VoiceOver assistive path, Reduce Motion honored,
  every new colour ≥4.5:1 on its surface in both themes, by test.
