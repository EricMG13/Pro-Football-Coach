# Archive — no authority

Every file in this folder is history. It describes a **different product** from the one this repo
is now building: a pro-only franchise simulator with direct player control on the field.

The project is now a **unified college→pro coaching career simulator with no direct control of
players during play**. Nothing here is canon, nothing here is a specification, and nothing here
should be implemented, cited as a decision, or treated as an argument that a question is already
settled.

Read these files only as evidence about what was tried before. Why each one was archived, and where
its role now lives, is recorded in [`../DOC-MANIFEST.md`](../DOC-MANIFEST.md).

Two warnings for anyone reading here:

- **`06-PLAYED-GAME-MODE.md` and `plans/2026-08-09-arcade-all22.md` specify direct player control**
  — throwing passes, controlling the ball carrier, a kick meter. That mode is forbidden by the
  current mission. Do not build it, and do not treat its detail as a sign it survived the rebuild.
- **`00-EXECUTIVE-PLAN.md`, `02-GAME-DESIGN.md` and `04-SCREENS-UI.md` describe a 32-team pro-only
  league.** The current scope is one save spanning a college tier and a pro tier. Team tables,
  league shapes and screen lists here are not the ones being built.

Links inside these files point at paths as they were before the archive move. They are not repaired,
because a historical document that has been silently edited stops being evidence.
