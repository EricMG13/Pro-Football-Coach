# Coaching HQ C — Film Cut versus Claude Design references

**Design-specificity verdict:** Candidate C is authored, football-native, and materially game-like. It is not generic application UI or AI-shaped slop. ## Priority issues

- **P0: none.**
- **P1 — false commit truth:** selecting Pass Rush or Ball Security still saves and announces Run Fits (`film-room.js:204-209`; `hq-c.html:96`). Confirmation must derive selected focus, cost, and consequence from the read model.
- **P1 — delegation is unresolved:** Delegate announces success but leaves choices active, Continue disabled, and no Take Back Control path (`film-room.js:178-186`). Delegation must settle authority, save, and progression.

- **P2 — read-model mapping is too coarse:** several visible facts lack one-to-one field paths.

## Versus Claude

### C should inherit

- One dominant verdict sentence.
- One compact benchmark or median tick so the causal evidence has numeric scale.
- At most three sourced outliers, with sample and confidence adjacent.
- Exact continuity language: what saved, when, where resume returns, and who now owns the decision.
- AX5's rule that the load-bearing sentence and primary action survive.
- One restrained team/save identity stroke.

### C should reject

- The rounded detail card as the dominant management-screen container.
- 10–11px analytics labels.
- Static chartreuse such as `SCOUTED`.
- Generic form bars or key-player blocks without a causal link to the current choice.
- Passive whitespace that turns a decision destination into a report viewer.
- Claude's admitted lack of management light, AX5, 932, empty, and error coverage.

## Persona red flags

- **Commuter:** delegation looks complete but does not unlock progress; save certainty is least reliable at the moment the player must pocket the phone.
- **Long-career power user:** the permanent 43% film cut may become repetitive, and the primary action is below the first AX5 viewport.
- **Football tactician:** the caption is convincing, but the diagram does not independently show which side owns each mark or how the weak-side fit fails.
- **Accessibility-dependent user:** default type and target floors pass, but safe areas and visually overlaid state announcements do not.

## Minor observations

- C's continuous ruled surface, timecode, telestration, and causal decision bands are more game-specific than Claude's rounded analytics pane.
- Claude's Opponent Report is calmer and better at benchmarked scanning, but its verdict conflates opponent rushing output with the user's run defence (`Screens-v2.dc.html:256-262`).
- Candidate C has exact dual-size exports, light, AX5, and multiple states; Claude's management reference explicitly admits those gaps (`Screens-v2.dc.html:303`).
- Candidate C passes the 12px text and 44px target floors at 844; Claude's native Opponent frame contains ten 10–11px leaf text items.
