ColumnSet Registry 8 — provisional

A segmented switch swaps the fact columns while the identity columns hold position (density model T8: the answer to the reference's fifteen columns is never horizontal scroll). One tap per lens; zero working memory, because the rows never move and identity never leaves the frame. Segments are 44 pt tall.

A set is a lens, and the budget prices the lens. §4.5 allows six to nine fact columns beside identity, and that band governs what is visible at once — which is exactly what one set is. So each set below draws six fact columns beside the three identity columns: Overview is slot, overall, age, class, fit, value; Contract is salary, guaranteed, years, expires, value, status. Count them in the header rows — the number written here is the number drawn. The two sets together carry eleven distinct facts, more than any single view may hold, which is the whole purpose of the component: further facts arrive as column sets, never as horizontal scroll. Value is the one fact both sets hold, deliberately: the extension decision is salary against worth, and making a coach swap lenses to compare them would spend working memory, which §4.5 never permits.
