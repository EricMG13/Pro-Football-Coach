Pro Football Coach — DESK register reference sheet. Registry entry 23 of docs/04-UX-AND-DESIGN-SYSTEM.md §6.5 — EmptyState / ErrorBanner / InterruptedState, "the failure set, inside the owning composition — noted undrawn in every prior pass" (reference-library-plan §3 entry 23). Drawn as approval cards, 2026-08-12. This is the sheet chrome-v3 card 1 defers to for loading, empty, error and interrupted.

This sheet is a rendering, not canon. docs/04-UX-AND-DESIGN-SYSTEM.md is the only canonical home; a value appearing only in a sheet has not shipped. Every hex value and every contrast ratio below is quoted from 04 §6.1 as written (G-07 write-back); no ratio was recomputed here, and any pair canon has not measured is flagged as a gap rather than given an invented number.

The governing rule, quoted: "Empty, error, interrupted and resume states remain inside the composition they belong to" and "Loading never displays invented percentage progress" (04 §7). A failure state drawn as a floating full-screen apology strips the frame of "visible team, opponent, season, person, place, football object or consequence" — the application-slop rejection of 04 §4.4. Every state on this sheet therefore keeps the world strip and its owning screen's chrome; the state occupies only the region whose content it stands in for. The five states beneath an owning screen — loading, empty, error, interrupted, delegated — are states, not screens, under the 04 §8 counting rule.

Self-contained HTML and CSS. No JavaScript, no CDN, no web font, no icon font, no images. System type stack; a glyph is an SF Symbol name written as text in a small monospace chip standing in for the 16 pt symbol. CSS px are read as pt. Light and dark are rendered side by side as explicit sections. DESK register: near-navy work surfaces, restrained violet furniture, matte opaque, hairline rules, radii 8/8/10, spacing steps 4/6/8/12/16/20, dense 24–28 pt rows, 10–12 pt micro type, tabular numerals (04 §6.1–§6.4). Registry entry 23 is provisional under the P11 three-production-uses rule; these cards are for owner approval. All identities are mechanical placeholders — pending generator output; the name-collision and trade-dress tests govern anything later generated for them. Player-facing copy is written out in full — short and plain, no blame, no jargon, no placeholder prose.

One continuous scenario across all five cards: Example State (EXS, dark-primary trio chip), Coach Sample, Week 9, Prep phase, record 6-2. Sources: 04 §2, §4.4, §4.5, §6.1–6.5, §7, §8 counting rule; briefs 2026-08-12 reference-library-plan §3–5 (§4 ten-point contract), density-model §5, sourcing-log rows Q1 (44 pt floor), Q2 (Reduce Motion substitutions), Q4 (widths and insets), Q5 (AX5 sizes).
