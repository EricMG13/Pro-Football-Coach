Logo-fit review before renaming

These are shipped marks, not mockups. The proposed suffix must name what the mark visibly depicts.

Recommended rule
A

Motif-preserving familiar names

Rename only to a common mascot the existing silhouette clearly supports. Keep an old suffix when a broader name would mislabel the artwork.

B

Aggressive common-name pass

Force every mark into a familiar mascot category. Shorter names, but some tools, trades, and characters become misleading.

C

Rename freely, redraw later

Choose names without respecting current art, then replace mismatched marks. Highest freedom and by far the largest scope.
