Components — two registers, one system
Every component now declares a register: BROADCAST (zero radius, team-coloured, tabular numerals, lives over the field) or DESK (radius m, neutral surfaces, team colour as a single stroke). v1 had one register and it was the desk, which is why a football game looked like an admin tool. Only the components whose appearance actually changes are redrawn here.
Sample identities synthetic throughout. Contrast figures computed against the surface each element composites on.

NOW IN 04 — WRITTEN, NOT PROPOSED
Register is a component property
Every registry entry declares BROADCAST or DESK, and the register fixes radius, numerals and whether team colour fills or strokes. §2.3's per-component radius table is replaced by a per-register rule.
ScoreBug joins the registry
Three variants — full, compact, live. It appears on the match view, aftermath, league readouts and the career line, so assembling it ad hoc per screen is how it drifts back to grey.
Sparkline is bars, and says so
§3 allows "a small fixed-count bar or line run". A line interpolates between five discrete games. Drop the line option.
Still undrawn: the failure set
ErrorBanner and EmptyState are unbuilt in v1 and v2 alike. §6 makes "every error path terminates in a presented surface" a contract test, and the prior build's exact failure was a silent error sink.
